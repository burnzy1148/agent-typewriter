## Install

```sh
code --install-extension burnzy1148.agent-typewriter
```

Or search for **Agent Typewriter** in the Extensions view. To install a build from a [GitHub release](https://github.com/burnzy1148/agent-typewriter/releases) instead, download the `.vsix` and run `code --install-extension agent-typewriter-<version>.vsix`. Then run **Agent Typewriter: Start Watching** and let your agent work. These docs describe version {pkg.version}.

## What it does

<CardGrid>
  <Card title="Replays, never touches your files" icon="approve-check">
    Replay happens in mirror documents with full syntax highlighting. Your real files are never written.
  </Card>
  <Card title="Types like a human" icon="pencil">
    Changes are planned line by line and word by word, so renaming a variable retypes only that word.
    Playback speeds up when the agent gets ahead.
  </Card>
  <Card title="Highlights like a git diff" icon="document">
    Added text stays green and removed text is marked, so you can see what changed at a glance. [Highlights](/docs/highlights/)
  </Card>
  <Card title="Replays git history too" icon="code-branch">
    Type out a branch, pull request or commit range that was never watched. [Replaying git history](/docs/git-history/)
  </Card>
</CardGrid>
